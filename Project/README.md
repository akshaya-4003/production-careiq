# CareIQ

**Customer experience and order risk platform for Northlane Retail Co.**

CareIQ watches every in-flight order, predicts which ones are about to turn into a
complaint, answers customer questions from six published policy documents (and
nothing else), drafts a resolution for an order, and stops any resolution that
commits money above an associate's authority until a manager approves it.

> No money is ever committed on the word of a model alone. Every figure comes from a
> trained model or a written rule. Language models only explain and write.

## Quick start (about 3 minutes)

Run every command from this `Project/` folder.

```bash
pip install -r requirements.txt          # 1. install (Python 3.9+)
cp .env.example .env                     # 2. optional; every setting has a default

python3 run_data_generation.py           # 3. check the 9 datasets and 6 PDFs are present
python3 run_database_setup.py            # 4. create database/careiq.db + 4 demo accounts
python3 run_data_preparation.py          # 5. profile the dirt, write clean tables to processed/
python3 run_model_training.py            # 6. 13-candidate bake-off, 3 models saved (~1 min)
python3 run_knowledge_indexing.py --backend offline   # 7. chunk + embed the policies

python3 run_api_service.py               # 8. REST service on :8080 (keep running)
python3 -m streamlit run run_dashboard.py   # 9. dashboard on :8501 (second terminal)
```

Then open <http://localhost:8501> and sign in:

Interactive API docs: <http://localhost:8080/docs>

## No API key needed

CareIQ runs end to end with **no key and no network**, using deterministic offline
backends:

- **Language model:** `OfflineClient` reads the facts in each prompt and answers in
  the requested format. Put a `GEMINI_API_KEY` in `.env` to use Gemini instead.
- **Embeddings:** `OfflineEmbedder`, a hashed bag of words. Install
  `requirements-models.txt` and re-index with `--backend minilm` for
  all-MiniLM-L6-v2.

`GET /health` and the dashboard sidebar always show which backends are running.

## Runtime notes

- Target runtime is **Python 3.9.1**; `requirements.txt` pins the newest versions
  that still support it. The code also runs on newer Pythons and newer library
  versions (it was verified on Python 3.14). `scripts/check_python39_syntax.py`
  guards against newer syntax creeping in.
- Storage is SQLite (`database/careiq.db`, paused runs in `database/checkpoint.db`)
  and an on-disk Chroma store (`database/chroma_store/`).
